## What an agent should know first

World Kinect runs no public developer program. As of 2026-08-29 there is no developer portal,
no API reference, no OpenAPI/Swagger document, no GraphQL endpoint, no MCP server, no A2A agent
card and no published rate limits or API plans on any host the company controls. Digital
delivery is customer-portal-first, and machine integrations (for example the fuel-price feed
that flight-planning platforms such as Leon Software consume) are arranged commercially with
the customer's account team rather than self-served.

The only anonymously readable machine-readable document the company publishes is its OpenID
Connect discovery metadata, for the identity tenant behind the myWorld customer portal.
